📊 ESTRUTURA DO BANCO DE DADOS:
════════════════════════════════════════════════════════════════════════════

TABELAS IMPLEMENTADAS:
  • Incorporadora          - Dados da construtora
  • Empreendimento        - Projeto imobiliário
  • Unidade               - Apartamento/casa
  • Planta                - Planta arquitectônica (com matching logic)
  • ImagemEmpreendimento  - Fotos (fachada, áreas comuns, etc)
  • Arquitetura           - Projeto arquitetônico
  • Paisagismo            - Projeto paisagístico
  • Decoracao             - Sugestões de decoração
  • Lazer                 - Áreas de lazer
  • Sustentabilidade      - Certificações verdes
  • Profissional          - Arquitetos, paisagistas, decoradores
  • HistoricoPreco        - Tracking de preços ao longo do tempo
  • PlanoPagamento        - Condições de financiamento
  • Importacao            - Log de importações (TABELAO, BOOK, etc)

RELACIONAMENTOS:
  - 1 Incorporadora → N Empreendimentos
  - 1 Empreendimento → N Unidades
  - 1 Empreendimento → N Plantas
  - 1 Planta → N Unidades (matching automático)
  - 1 Unidade → N HistoricoPreco
  - 1 Unidade → N PlanoPagamento

🚀 COMO USAR:
════════════════════════════════════════════════════════════════════════════

1️⃣  SETUP LOCAL (em 5 minutos):
    $ git clone https://github.com/KauaNovS/novalis.git
    $ cd novalis
    $ cp .env.example .env
    $ docker-compose up -d
    $ cd backend && npm install && npm run db:migrate
    $ npm run dev

2️⃣  TESTAR:
    $ curl http://localhost:5000/health
    $ curl http://localhost:5000/api

3️⃣  DESENVOLVIMENTO:
    Terminal 1: cd backend && npm run dev
    Terminal 2: cd frontend && npm run dev
    Acesse: http://localhost:3000

4️⃣  DEPLOY:
    git push origin main  # Triggers CI/CD automaticamente
