📥 PASSO A PASSO PARA FAZER DOWNLOAD E GIT PUSH:
═══════════════════════════════════════════════════════════════════════════

1️⃣  BAIXAR OS ARQUIVOS (já devem estar disponíveis para download)

2️⃣  CRIAR A ESTRUTURA LOCAL:
    
    mkdir -p ~/novalis
    cd ~/novalis
    
    # Criar subpastas
    mkdir -p .github/workflows
    mkdir -p backend/src
    mkdir -p backend/prisma

3️⃣  COPIAR OS ARQUIVOS para as pastas corretas:
    
    ✅ Na raiz (novalis/):
       - 00_LEIA_PRIMEIRO.txt
       - README.md
       - QUICKSTART.md
       - DEPLOY_INSTRUCTIONS.md
       - PROJECT_SUMMARY.txt
       - ESTRUTURA.txt
       - .env.example
       - .gitignore
       - LICENSE
       - docker-compose.yml
    
    ✅ Em .github/workflows/:
       - ci.yml
    
    ✅ Em backend/:
       - package.json
       - tsconfig.json
       - Dockerfile
    
    ✅ Em backend/src/:
       - index.ts
    
    ✅ Em backend/prisma/:
       - schema.prisma

4️⃣  CONFIGURAR GIT E FAZER PUSH:
    
    cd ~/novalis
    
    git init
    git branch -M main
    git config user.name "Kauã Santos Novaes"
    git config user.email "seu-email@gmail.com"
    
    git add .
    git commit -m "chore: initial Novalis project structure"
    
    git remote add origin https://github.com/KauaNovS/novalis.git
    git push -u origin main
